
# Principais Propriedades CSS 🔧

Aqui vai uma lista prática das **propriedades CSS mais usadas** pra estilizar suas páginas com eficiência. Essas são as que você vai usar o tempo todo!

---

## 🎨 Cores e Texto

| Propriedade         | Exemplo                     | O que faz                                  |
|---------------------|-----------------------------|--------------------------------------------|
| `color`             | `color: blue;`              | Cor do texto                               |
| `background-color`  | `background-color: yellow;` | Cor de fundo                               |
| `font-size`         | `font-size: 18px;`          | Tamanho da fonte                           |
| `font-family`       | `font-family: Arial;`       | Tipo da fonte                              |
| `font-weight`       | `font-weight: bold;`        | Negrito                                    |
| `text-align`        | `text-align: center;`       | Alinhamento do texto                       |
| `text-decoration`   | `text-decoration: underline;` | Sublinhado, linha etc                    |

---

## 📦 Espaçamento e Layout

| Propriedade | Exemplo              | O que faz                              |
|-------------|----------------------|----------------------------------------|
| `margin`    | `margin: 10px;`      | Espaço externo                         |
| `padding`   | `padding: 20px;`     | Espaço interno                         |
| `width`     | `width: 300px;`      | Largura                                |
| `height`    | `height: 150px;`     | Altura                                 |
| `display`   | `display: flex;`     | Tipo de exibição (ex: block, flex...)  |
| `gap`       | `gap: 10px;`         | Espaço entre elementos (em flex/grid)  |

---

## 🧱 Bordas e Caixas

| Propriedade     | Exemplo                       | O que faz                        |
|-----------------|-------------------------------|----------------------------------|
| `border`        | `border: 1px solid black;`    | Borda ao redor do elemento       |
| `border-radius` | `border-radius: 8px;`         | Arredondamento dos cantos        |
| `box-shadow`    | `box-shadow: 2px 2px 5px gray;` | Sombra da caixa                |

---

## 🖼️ Imagens e Planos de Fundo

| Propriedade         | Exemplo                                      | O que faz                          |
|---------------------|----------------------------------------------|------------------------------------|
| `background-image`  | `background-image: url('fundo.jpg');`        | Define imagem de fundo             |
| `background-size`   | `background-size: cover;`                    | Ajusta imagem ao tamanho do fundo  |
| `object-fit`        | `object-fit: cover;`                         | Cobre o espaço da imagem no contêiner |

---

## 💫 Efeitos e Transições

| Propriedade    | Exemplo                        | O que faz                              |
|----------------|--------------------------------|----------------------------------------|
| `transition`   | `transition: all 0.3s ease;`   | Transição suave entre mudanças         |
| `opacity`      | `opacity: 0.5;`                | Define transparência                   |
| `cursor`       | `cursor: pointer;`             | Define tipo de cursor ao passar mouse  |

---

## ✅ Dica

Quer testar tudo isso? Cria um elemento com `class="caixa"` e aplica:

```css
.caixa {
  background-color: #f9f9f9;
  color: #333;
  padding: 20px;
  margin: 10px;
  border-radius: 8px;
  box-shadow: 0 2px 6px rgba(0,0,0,0.1);
}
```

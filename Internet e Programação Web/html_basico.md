
# HTML Básico 🌐

HTML (HyperText Markup Language) é a **linguagem de marcação padrão** para criar páginas na web. Ele define a estrutura e o conteúdo de uma página.

---

## 📌 Estrutura Básica

```html
<!DOCTYPE html>
<html>
  <head>
    <title>Título da Página</title>
  </head>
  <body>
    <h1>Meu Primeiro Site</h1>
    <p>Bem-vindo ao mundo do HTML!</p>
  </body>
</html>
```

---

## 🔤 Principais Tags

| Tag         | Significado                          |
|-------------|--------------------------------------|
| `<!DOCTYPE>`| Declara o tipo de documento          |
| `<html>`    | Início do documento HTML             |
| `<head>`    | Cabeçalho (informações da página)    |
| `<title>`   | Título que aparece na aba do navegador |
| `<body>`    | Corpo da página (conteúdo visível)   |

---

## 📝 Títulos e Parágrafos

```html
<h1>Título Principal</h1>
<h2>Subtítulo</h2>
<p>Este é um parágrafo.</p>
```

---

## 🔗 Links

```html
<a href="https://www.exemplo.com">Visite o site</a>
```

---

## 🖼️ Imagens

```html
<img src="imagem.jpg" alt="Descrição da imagem" width="200">
```

---

## 📋 Listas

### Lista não ordenada:

```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
</ul>
```

### Lista ordenada:

```html
<ol>
  <li>Primeiro</li>
  <li>Segundo</li>
</ol>
```

---

## 🧩 Tabelas

```html
<table border="1">
  <tr>
    <th>Nome</th>
    <th>Idade</th>
  </tr>
  <tr>
    <td>Ana</td>
    <td>20</td>
  </tr>
</table>
```

---

## 🧠 Boas Práticas

- Sempre comece o documento com `<!DOCTYPE html>`
- Use indentação para melhorar a legibilidade
- Use `alt` nas imagens para acessibilidade
- Use títulos hierárquicos: `<h1>` até `<h6>`

# Atividade de Python - para próxima semana, colocar no caderno.

### 1. Contador de Vogais
Crie uma função `contar_vogais` que recebe uma string e retorna o número de vogais (a, e, i, o, u), case-insensitive.

### 2. Verificação de Número Primo
Desenvolva uma função `eh_primo` que recebe um número inteiro e retorna True se for primo, False caso contrário.

### 3. Calculadora Simples
Implemente uma função `calculadora` que recebe dois números e uma operação (+, -, *, /) e retorna o resultado ou mensagem de erro.

### 4. Fatorial com Recursividade
Crie uma função recursiva `fatorial` que calcula o fatorial de um número inteiro não negativo.

### 5. Conversor de Temperatura
Implemente uma função `converter_temperatura` que converte entre Celsius e Fahrenheit.

### 6. Gerador de Sequência Fibonacci
Crie uma função `fibonacci` que recebe um número n e retorna uma lista com os primeiros n termos da sequência de Fibonacci.

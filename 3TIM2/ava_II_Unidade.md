## 🌐 Internet e Programação Web

### 🏗️ Trabalho Prático – Desenvolvimento de Site com CSS Interativo

**Objetivo:**  
Desenvolver um site completo, com foco em navegação por menu e aplicação de efeitos visuais utilizando **CSS3**.

**Requisitos obrigatórios:**
- Estruturação com HTML5.
- Mínimo de 3 páginas interligadas via menu de navegação.
- Aplicação de efeitos com CSS (ex: transições, transformações, animações, hover).
- Responsividade básica.
- Estética coerente (uso de cores, tipografia e imagens).

**Entrega:**
- Arquivos do site organizados em pastas (`html`, `css`, `img`).
- Apresentação do projeto com explicação das escolhas de design e funcionalidades.
